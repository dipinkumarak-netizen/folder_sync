# Project Vision

OpenBackup is an open source Android backup and synchronization application
built with Flutter.

Primary target:

- Local Storage → FTP Backup
- FTP Synchronization
- Scheduled Backup
- Restore
- Backup History
- Completely Offline
- AMOLED Dark Theme
